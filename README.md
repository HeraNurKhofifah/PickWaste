# PickWaste

PickWaste adalah aplikasi berbasis web yang dibuat untuk membantu pengelolaan penjemputan sampah secara digital antara masyarakat dan petugas.

## Latar Belakang
Pengelolaan sampah yang belum optimal mendorong perlunya sistem informasi yang dapat memudahkan masyarakat dalam melakukan penjemputan sampah serta memantau prosesnya secara daring.

## Tujuan
- Memudahkan masyarakat melakukan permintaan penjemputan sampah
- Membantu petugas dalam mengelola data penjemputan
- Meningkatkan efisiensi dan transparansi pengelolaan sampah

## Teknologi yang Digunakan
- Java Servlet
- JSP
- Apache Tomcat
- Maven
- MySQL
- HTML, CSS, JavaScript

## Fitur Utama
- Registrasi dan login pengguna
- Dashboard pengguna
- Pengajuan penjemputan sampah
- Manajemen data oleh petugas
- Sistem reward
- Fitur chat pengguna dan petugas

## Struktur Proyek
Project ini menggunakan struktur standar Maven.

## Cara Menjalankan
1. Import project ke NetBeans
2. Konfigurasikan database MySQL
3. Jalankan project menggunakan Apache Tomcat

## Catatan
Project ini dibuat untuk keperluan tugas perkuliahan.
